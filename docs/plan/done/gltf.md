# gltf

Landed. Behavior notes are the phase log. The checklist is the upstream file map for this module.

## Behavior

A glTF 2.0 subset has landed. `parse` reads one JSON document. Buffer bytes come from a base64 `data:` URI, or from the caller when buffer 0 has no URI. Triangle primitives become meshes with `POSITION`, `NORMAL`, `TEXCOORD_0`, and indices. `baseColorFactor` is written as linear RGB, with `roughnessFactor`, `metallicFactor`, and `doubleSided`. A double-sided material flips the shading normal on back faces. A back-sided material always flips it. Front-sided materials leave the normal alone. The flag is `surface.w`: `1` for double, `-1` for back, and `0` for front. `KHR_materials_unlit` becomes `MeshBasicMaterial`. `OPAQUE` ignores base-color alpha. `MASK` stores `alphaCutoff` as `alphaTest` (default 0.5) and discards fragments below it. `BLEND` is transparent and keeps that alpha, including 1. A node `matrix` replaces translation, rotation, and scale. A node camera becomes a perspective or orthographic camera. `yfov` is converted to degrees. A missing aspect ratio is 1, and a missing or zero far plane is 2e6, matching `GLTFLoader.loadCamera`. A node that only references a camera becomes that camera. A mesh and a camera on the same node become a group, and a repeated camera index is a separate object. Animations become clips: `translation` is `.position`, `rotation` is `.quaternion`, and `scale` is `.scale`. `LINEAR` and `STEP` map to linear and discrete sampling. A missing clip name is `animation_` plus its index. `CUBICSPLINE` stores an in-tangent, a vertex, and an out-tangent on each key. Quaternion samples are normalized. A `KHR_lights_punctual` directional light uses a linear color, intensity 1 when omitted, and a target at local `(0, 0, -1)`. Its position is reset to the origin before the node transform. The first visible point light adds a direct term. Attenuation is `1 / max(distance^decay, 0.01)`, and a positive distance smooths the light to zero at that cutoff. Decay defaults to 2. A glTF point light uses the node position, stores `range` as `distance` (`0` means no cutoff), and keeps intensity `0`. Point lights do not cast shadows. The first visible spot light adds an unshadowed direct term. It uses the same distance attenuation as a point light, then multiplies by a smoothstep from `coneCos` to `penumbraCos`. `angleCos` is the dot of the normalized vector from the fragment to the light and the normalized vector from the target to the light. `coneCos` is `cos(angle)` and `penumbraCos` is `cos(angle * (1 - penumbra))`. Equal cosines are a hard edge. A glTF spot light stores `outerConeAngle` as `angle` (default π/4), `penumbra` as `1 - innerConeAngle / outerConeAngle`, and `range` as `distance`. Decay is 2. Intensity 0 is kept. The target sits at local `(0, 0, -1)`. Spot lights do not cast shadows. The first four joint influences skin on the CPU. `JOINTS_0` and `WEIGHTS_0` select joints and weights. A missing pair leaves the mesh rigid. `JOINTS_1` and `WEIGHTS_1`, when both are present, add four more influences and are normalized together with the first four. A second set with only one of the two attributes is ignored. r186's loader attribute map has no `JOINTS_1` entry; the accessor rules match `JOINTS_0`. `JOINTS_2` and `WEIGHTS_2`, when both are present and the second set was read, add four more influences and are normalized with the earlier ones. A third set without the second set is ignored. r186's attribute map has no `JOINTS_2` entry either. `JOINTS_3` and `WEIGHTS_3`, when both are present and the third set was read, add four more influences and are normalized with the earlier ones. A fourth set without the third set is ignored. r186's attribute map has no `JOINTS_3` entry either. Weights are scaled so their absolute values sum to 1, and a zero weight vector becomes `(1, 0, 0, 0)`. The joint matrix is `joint.matrixWorld * inverseBindMatrix`. The skinned point is then multiplied by the inverse of the mesh `matrixWorld`, matching `SkinnedMesh` attached mode with the identity bind matrix `GLTFLoader` passes to `bind`. A missing `inverseBindMatrices` accessor uses identity. Each skinned primitive gets its own geometry, so an unskinned user of the same mesh keeps the bind pose. Position and, when present, normal are rewritten from that bind pose on every `update_frame`. A primitive that also has morph targets adds those `POSITION` and `NORMAL` displacements to the unbaked base before skinning, using the weights currently stored on the morph state. Color morphs stay on the morph write and are not skinned. PNG images, 8-bit and non-interlaced, decode to `rgba8`. JPEG is rejected. Bytes come from a data URI or from a buffer view whose mime type is `image/png`. Texture defaults are `flipY` false, linear magnification, linear-mipmap-linear minification, and repeat wrapping. A sampler overrides those. `texCoord` above 0 is rejected. Non-instanced triangle meshes are skinned in a compute shader from the bind pose plus morph deltas, then drawn from that buffer. Instanced meshes, lines, and points keep the CPU-rewritten attributes. The CPU path still rewrites position and normal on every `update_frame`. A mesh `weights` entry bakes that `POSITION` morph delta into the vertices and, when a normal attribute is already present, the `NORMAL` morph delta into those normals. A missing normal attribute skips the normal target. A node `weights` list overrides the mesh weights by index, and a shorter list keeps the later mesh weights. A node whose weights differ gets its own geometry. A `weights` animation channel becomes `.morphTargetInfluences` and rebakes position, normal, and color from the unbaked base. A node without morph targets skips that channel. The first write clones a shared geometry so other nodes keep their pose. A `COLOR_0` morph delta is baked into an existing color attribute, including a fourth component when the accessor is `VEC4`. A missing color attribute skips that target. A mesh color attribute is multiplied into the base color, including its alpha. A mesh without one is packed as white. Lambert and Standard add an emissive color after lighting, so it is not shadowed and is not multiplied by the vertex color. Basic materials leave it out. A glTF `emissiveFactor` is linear RGB and defaults to black; a channel of `0` is kept. Unlit materials ignore it. `KHR_materials_emissive_strength` stores `emissiveIntensity`, which defaults to 1 and is multiplied into the emissive uniform. A strength of 0 is kept. Unlit materials ignore it. An emissive map multiplies the emissive color. A missing map binds a white texture, so the color is unchanged. glTF `emissiveTexture` is assigned to `emissive_map` on lit materials. Unlit materials ignore it. A Standard roughness map multiplies roughness by the texture's green channel, then applies the 0.0525 floor. A missing map binds white, so the factor is unchanged. Lambert and Basic do not sample it. The sample shares bind group 3 with the emissive map: bindings 0 and 1 stay emissive, and 2 and 3 are roughness. Group 1 stays the two-binding color map. glTF `metallicRoughnessTexture` is assigned to both `roughness_map` and `metalness_map`. Unlit materials ignore it. A Standard metalness map multiplies metalness by the texture's blue channel, then clamps the product to [0, 1]. A missing map binds white. It uses bind group 3 bindings 4 and 5. Lambert and Basic do not sample it. The metalness map is that same texture, sampled from the blue channel. An alpha map multiplies fragment alpha by the texture's green channel after the vertex color, and before the alpha test. Fog does not change that alpha. Basic, Lambert, and Standard sample it. A missing map binds white. It uses bind group 3 bindings 6 and 7. Points and lines do not sample it. glTF does not read an alpha texture. Base color and emissive samples decode sRGB to linear with `SRGBToLinear` before shading. The color map's alpha stays as stored. Roughness, metalness, and alpha maps stay linear. A white texel stays white. Lambert and Standard can set `flatShading`. The flag is `emissive.w`: above 0.5, the shader replaces the vertex normal with the cross product of the screen derivatives of the view-space position, transformed back to world space, and skips the side flip. The uniform block stays 624 bytes. Basic materials store the flag and do not shade with it. A sparse accessor replaces indexed elements, and an accessor with no buffer view starts at zero. `examples/gltf` draws that unit box under a directional light. The window sample is `scripts/build-gltf.sh`. Host playback stays out of this pass.
